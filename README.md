# 🛒 Clone de Estudos - Loja Sapatella (Shopify)

Este repositório foi criado para documentar e registrar o meu processo de aprendizado e evolução em desenvolvimento web. O objetivo principal é recriar a interface da loja **Sapatella** (uma plataforma baseada em Shopify) para entender melhor a estrutura visual, a experiência do usuário (UX) e as práticas de desenvolvimento voltadas para o cenário de e-commerce.

> 🛠️ **Status do Projeto:** Em desenvolvimento (Estudos diários)

---

## 🎯 Objetivo do Projeto
* Desenvolver habilidades práticas com tecnologias fundamentais da web.
* Compreender a arquitetura visual e os componentes de páginas de alta conversão de lojas Shopify.
* Demonstrar consistência e evolução diária através de commits frequentes no GitHub.

## 🚀 Tecnologias Utilizadas (Planejadas/Em Uso)
* **HTML5** (Estruturação semântica)
* **CSS3** (Estilização e responsividade)
* **JavaScript** (Funcionalidades interativas básicas)
